# Trail apps

Static site for Nigel's trail tools, published from this repository with GitHub Pages.

- [Trail planner](trail/) — draw a hike on the map, snap it to trails, and export GPX.
- [Stretch 15](stretch/) — a 10–25 minute stretching routine that installs as a PWA.

## Apple Health logging (Stretch 15)

Stretch 15 can open an iOS Shortcut and pass the session length, in minutes, as text. The default shortcut name is **Log Stretch**; change it under **Apple Health logging** in the app if yours is different.

1. In the Shortcuts app, create a shortcut with that name.
2. Receive the text input, then log a Health sample (for example Mindful Minutes) using that number as the duration.
3. In Stretch 15, use **Test Shortcut** to confirm it logs 1 minute.

Gentle stretching only — stop if anything hurts.
